# design

このフォルダは、ゲーム固有の仕様・構想・設計意図を置く場所です。

## 置くもの

- ゲーム全体の仕様
- 戦闘システムの仕様
- ゲームサイクル
- アクターが振る舞えること
- アイテム、ゴールド、報酬、成長などのシステム
- マスタデータの設計意図
- Domainオブジェクトの設計意図
- 思いついた仕様案、将来構想、保留中のアイデア

## 置かないもの

- 他プロジェクトにも流用できる実装ルール
- コーディング規約
- デバッグ手順
- レビュー手順
- 汎用プロンプト

それらは `docs/guidelines/` に置きます。

## 判断基準

このゲームに固有の話なら `design` に置きます。
他のゲームや別プロジェクトにもそのまま持っていきたい話なら `guidelines` に置きます。

## 例

```text
戦闘システムで、味方4人が2x2グリッドに並ぶ
Rotateは90度時計回りで行動消費しない
MPはWaveをまたいで維持する
アイテムは所持数のあるものだけ表示する
```

上記はゲーム仕様なので、このフォルダの対象です。
