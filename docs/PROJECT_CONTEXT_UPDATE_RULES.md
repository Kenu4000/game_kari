# PROJECT_CONTEXT.md Update Rules

- ChatGPT updates `docs/PROJECT_CONTEXT.md`.
- Codex reads `docs/PROJECT_CONTEXT.md` as reference, but must not edit `docs/*` unless explicitly instructed.
- Important finalized changes should be reflected in `docs/PROJECT_CONTEXT.md`.
- When ChatGPT updates `docs/PROJECT_CONTEXT.md`, important project-history items should also be added to its `Work log` section.
- Work log entries should be grouped by date and written as short factual bullet points.
- Work log entries should record decisions, completed work, important failures, and follow-up actions.
- After attempting an update, ChatGPT reports whether the update succeeded or failed.
- If updating fails, ChatGPT provides copyable text for manual reflection.
