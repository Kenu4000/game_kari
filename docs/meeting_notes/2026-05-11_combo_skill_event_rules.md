# 合体技・戦闘間イベント仕様確認メモ

## 概要

ChatGPTからの確認質問に対する回答として、合体技の技枠、MP消費、戦闘間イベントの扱いについて確定・保留事項を整理する。

## 合体技と技枠

- 合体技は、通常技と同じくキャラクターの技枠を使うものとして考える。
- 現時点では技枠は4つを想定している。
- ただし、最後まで4枠に固定するか、将来的に枠を増やすかは今後検討する。
- 合体技を技枠に入れることで、通常技・補助技・合体技の取捨選択を発生させる。

## 合体技のMP消費

- 基本仕様では、合体技のMP消費は使用者のみが支払う。
- 相方のMPは基本的には消費しない。
- ただし、技ごとのメリット・デメリットとして、相方のMPも消費する特殊な合体技があってもよい。
- 初期設計では、MP消費ルールを複雑にしすぎないため、使用者のみ消費を基本にする。

## 戦闘間イベントの扱い

- 重要なイベントは、休憩・死体漁りの選択肢として選ばせない。
- 重要イベントは、休憩・死体漁りの分岐前、または分岐後に強制的に発生させる。
- 休憩・死体漁りのアイコン右上などに会話マークが出るのは、主にサブイベント用とする。
- サブイベントは、片方の選択肢を選ばず発生しなかった場合でも、次のwave後の選択肢で再び発生する可能性がある。
- 重要イベントを見逃す不安は減らしつつ、サブイベントでは行動選択との結びつきを作る。

## 設計意図

- 合体技を技枠に含めることで、拠点での技選択に意味を持たせる。
- 合体技のMP消費を使用者中心にすることで、条件管理とMP管理が過剰に複雑にならないようにする。
- 重要イベントを強制発生にすることで、物語や合体技解放の重要導線をプレイヤーが取り逃がしにくくする。
- サブイベントを戦闘間選択に付随させることで、休憩・死体漁りにキャラクター面の意味を追加する。
